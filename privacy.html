好奇心チャンネル 投稿ツール

プライバシーポリシー

制定日：2026年11月9日

このポリシーは、YouTube チャンネル「好奇心チャンネル」の運営者（以下「運営者」）が使う個人用のツール「好奇心チャンネル 投稿ツール」（以下「本ツール」）での、情報の扱いを説明するものです。本ツールを使うのは運営者本人だけです。

1. YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。本ツールを使うことは、YouTube 利用規約に同意することを意味します。Google による情報の扱いについては、Google プライバシーポリシーをご覧ください。

2. 取得する情報

運営者が Google アカウントで本ツールを許可したとき、本ツールは次の権限だけを求めます。

  • 動画の投稿（youtube.upload）：運営者のチャンネルに動画とサムネイルを投稿するため
  • YouTube アカウントの閲覧（youtube.readonly）：投稿先のチャンネル名と ID、投稿した動画の状態を確かめるため

この許可により、本ツールは Google から認証情報（アクセストークンと更新トークン）を受け取ります。API から読み取るのは、運営者自身のチャンネルの名前と ID、本ツールで投稿した動画の状態（YouTube 側の処理の状況、公開範囲、タイトルなど）だけです。

3. 利用目的

取得した情報は、運営者のチャンネルへの動画とサムネイルの投稿、および投稿が正しく行われたかの確認にだけ使います。広告、分析、その他の目的には使いません。

4. 保存

認証情報と投稿の記録（動画の ID、投稿日時、公開範囲など）は、運営者のパソコンの中にだけ保存します。外部のサーバーに送ったり、公開したりしません。

5. 共有

取得した情報を第三者に提供、販売、貸与することはありません。Google（YouTube）に送る情報は、投稿と確認のために必要なものだけです。

6. 運営者以外の方の情報

本ツールは、運営者以外の YouTube ユーザーの情報（コメント、視聴者の情報など）を取得しません。

7. アクセスの取り消しと削除

本ツールへのアクセスの許可は、Google アカウントのセキュリティ設定のページから、いつでも取り消せます。取り消したときは、運営者のパソコンに保存した認証情報も削除します。

8. Cookie とアクセスの記録

本ツールとこのウェブサイトは、Cookie を使いません。このウェブサイトは GitHub Pages で公開しているため、GitHub がアクセスの記録を取る場合があります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

9. 変更

このポリシーを変更するときは、このページを更新し、制定日の下に改定日を記載します。

10. お問い合わせ

このポリシーについてのお問い合わせは、好奇心チャンネルまでお願いします。

Privacy Policy (English)

Effective date: November 9, 2026

This policy describes how 好奇心チャンネル 投稿ツール (Koukishin Channel Uploader, “the Tool”) handles information. The Tool is a personal tool used only by the operator of the YouTube channel “好奇心チャンネル” (“the Operator”).

1. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. For how Google handles information, see the Google Privacy Policy.

2. Information accessed

When the Operator authorizes the Tool with a Google account, the Tool requests only these scopes: youtube.upload (to upload videos and thumbnails to the Operator’s channel) and youtube.readonly (to read the channel name and ID and the status of the uploaded videos). The Tool receives OAuth tokens (an access token and a refresh token) from Google. Through the API it reads only the Operator’s own channel name and ID and the status of videos uploaded with the Tool (processing status, privacy status, title, and similar).

3. How information is used

This information is used only to upload videos and thumbnails to the Operator’s channel and to confirm that the uploads succeeded. It is not used for advertising, analytics, or any other purpose.

4. Storage

OAuth tokens and upload records (video ID, upload time, privacy status, and similar) are stored only on the Operator’s own computer. They are not sent to any other server and are not made public.

5. Sharing

The Tool does not provide, sell, or rent this information to third parties. Only the data needed for uploading and confirming videos is sent to Google (YouTube).

6. Data about other users

The Tool does not collect any information about YouTube users other than the Operator, such as comments or viewer data.

7. Revoking access and deletion

Access granted to the Tool can be revoked at any time on the Google security settings page. When access is revoked, the tokens stored on the Operator’s computer are also deleted.

8. Cookies and access logs

Neither the Tool nor this website uses cookies. This website is hosted on GitHub Pages, and GitHub may keep access logs. See the GitHub General Privacy Statement.

9. Changes

If this policy changes, this page will be updated and the revision date will be shown below the effective date.

10. Contact

For questions about this policy, please contact 好奇心チャンネル on YouTube.

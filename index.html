好奇心チャンネル 投稿ツール

YouTube チャンネル「好奇心チャンネル」の運営者が、自分のチャンネルに動画を投稿するために使う個人用のツールです。

YouTube チャンネル プライバシーポリシー

このツールがすること

  • 運営者が制作した動画、サムネイル、タイトル、説明文を、YouTube Data API を使って運営者自身のチャンネルに投稿します。
  • 投稿した動画の状態（YouTube 側の処理の状況、公開範囲、タイトル）を読み取り、投稿が正しく行われたかを確かめます。

利用できる人

運営者本人だけです。一般の方が登録したり、ログインしたりして使うサービスではありません。運営者以外の YouTube ユーザーの情報は扱いません。

個人情報と Google アカウントの情報の扱いは、プライバシーポリシーをご覧ください。

お問い合わせは、好奇心チャンネルまでお願いします。

About this tool (English)

好奇心チャンネル 投稿ツール (Koukishin Channel Uploader) is a personal tool used only by the operator of the YouTube channel “好奇心チャンネル” (Koukishin Channel).

  • It uploads videos, thumbnails, titles and descriptions created by the operator to the operator’s own channel through the YouTube Data API.
  • It reads the status of the uploaded videos (processing status, privacy status, title) to confirm that each upload succeeded.

It is not a service for the public: no one other than the operator signs in to it, and it does not handle data about any other YouTube user. See the Privacy Policy.
